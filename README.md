# farsiyar-media

Lesson films for the «فارسیار» study app (scroll-driven cinematic videos). Downloaded by the app on demand
(through jsDelivr or raw.githubusercontent.com) and kept on the phone for offline use.

- `fa9/<lessonId>.mp4` — فارسی نهم. H.264, 480×854, 24 fps, keyframe every 8 frames (fast seeking), no audio.

The films are AI-generated (images: GPT Image; video: Google Veo 3.1 Lite, via ElevenLabs) for educational use.
